# صورة صفحة التواصل — Contact page portrait

ضع صورتك هنا بأحد هذه الأسماء (الأولوية بالترتيب):

```
profile.webp   ← الموصى به
profile.jpg
profile.png
```

- استبدل الملف **بنفس الاسم** وستظهر الصورة الجديدة تلقائيًا **بدون أي تعديل في الأكواد**.
- تُعرض بنسبة 4:5 مع `object-fit: cover` وتذوب حوافها في خلفية الصفحة (بدون برواز).
- نفس الصورة تظهر أيضًا في **بطاقة التعريف الرقمية** (`/#card`).
- لو الوجه اتقص بشكل غير مناسب، عدّل متغير البيئة (بدون كود):
  ```
  VITE_CONTACT_PROFILE_POSITION=50% 18%
  ```

## توصيات

- بورتريه عمودي حوالي 1000×1250px أو أكبر.
- خلفية داكنة، حجم أقل من 500KB (WebP أفضل).
