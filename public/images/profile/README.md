# صورة الصفحة الرئيسية — Home page portrait

هذه الصورة هي **خلفية الصفحة الرئيسية بالكامل**.

ضع صورتك هنا بأحد هذه الأسماء (الأولوية بالترتيب):

```
yousef-ahmed.webp   ← الموصى به
yousef-ahmed.jpg
profile.webp
profile.jpg
profile.png
```

- استبدل الملف **بنفس الاسم** وستظهر الصورة الجديدة تلقائيًا **بدون أي تعديل في الأكواد**.
- الصورة تملأ الشاشة كاملة (`object-fit: cover`):
  - على الديسكتوب يُقصّ الجانب المقابل للنص (الوجه يظهر دائمًا في الجهة الأخرى).
  - على الموبايل يُركز القص على أعلى الصورة.
- لو الوجه مش ظاهر صح، عدّل متغير البيئة (بدون كود):
  ```
  VITE_HOME_PROFILE_POSITION=50% 12%
  ```

## توصيات

- بورتريه عمودي حوالي 1200×1600px أو أكبر.
- خلفية داكنة (كحلي/فحمي) لتذوب في خلفية الصفحة.
- حجم أقل من 500KB (WebP أفضل).
