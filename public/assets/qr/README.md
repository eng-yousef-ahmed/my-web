# كود QR — صفحة التواصل

ضع الكود هنا باسم:

```
contact-qr.png      (الاسم الأساسي)
contact-qr.svg      (بديل)
contact-qr.webp     (بديل)
contact-qr.jpg      (بديل)
```

- استبدل الملف **بنفس الاسم** وسيظهر الكود الجديد تلقائيًا بدون أي تعديل في الأكواد.
- اجعل الكود **قابلًا للمسح** باختباره بهاتف حقيقي قبل الرفع.

## قبل ما تضيف ملفك

الموقع يعرض حاليًا كود QR يشير إلى موقعك (`tech-of-the-world.netlify.app`)
مولّد من خدمة خارجية — يعمل ويُمسح فورًا. لو حطيت ملفك هنا، هو اللي هيتعرض مكانه.

## توصيات

- مربع 480×480px أو أكبر.
- لو الكود بخلفية شفافة أو فاتحة، الصفحة بتعرضه على سطح داكن شبه شفاف —
  الأفضل كود **فاتح على خلفية داكنة** (`#0A1420`) ليتناغم مع التصميم.
