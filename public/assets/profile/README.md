# صورة صفحة التواصل — Contact page profile image

ضع صورتك هنا باسم:

```
profile.jpg     (الاسم الأساسي)
profile.webp    (بديل — أخف)
profile.png     (بديل)
```

- استبدل الملف **بنفس الاسم** وستظهر الصورة الجديدة تلقائيًا بدون أي تعديل في الأكواد.
- الصورة تملأ الشاشة كاملة (`object-fit: cover`) مع قصّ ثابت يركز على الجزء العلوي.

## لو الوجه اتقص في صورتك الجديدة

عدّل موضع القص من متغير البيئة (بدون لمس أي كود):

```
VITE_CONTACT_PROFILE_POSITION=50% 12%
```

القيمة الافتراضية `50% 18%`. جرّب قيمًا مثل `50% 8%` (أعلى) أو `50% 25%` (أنزل).

## توصيات

- اتجاه عمودي (بورتريه) — حوالي 1200×1600px أو أكبر.
- خلفية داكنة (كحلي/فحمي) لتذوب في خلفية الصفحة السينمائية.
- حجم أقل من 500KB (WebP أفضل).
