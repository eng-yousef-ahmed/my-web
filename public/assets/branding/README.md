# لوجو صفحة التواصل — Contact page logo

ضع اللوجو هنا باسم:

```
logo.svg        (مفضل — متجه حاد في كل المقاسات)
logo.png        (بديل)
```

- استبدل الملف **بنفس الاسم** وسيظهر اللوجو الجديد تلقائيًا بدون أي تعديل في الأكواد.
- يُعرض اللوجو على خلفية داكنة (فوق الصورة) — استخدم نسخة **بيضاء/فاتحة**.
- الارتفاع المعروض ~40–48px والعرض تلقائي — صمّم اللوجو أفقيًا (عرض ≈ 4–7× الارتفاع).
- لو حذفت الملفين معًا، الموقع يرجع للوجو الأساسي في `public/logo-light.svg` ثم علامة YA المدمجة.
