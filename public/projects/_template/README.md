# إضافة مشروع جديد (بدون أي تعديل في الكود)

كل مشروع = مجلد واحد داخل `public/projects/` يحتوي ملف `meta.json` ومجلد `images/`.

```
public/projects/
├── index.json                  ← قائمة أسماء مجلدات المشاريع
├── clinic-network/             ← مثال: مشروع جديد
│   ├── meta.json               ← تفاصيل المشروع (انسخ القالب meta.example.json)
│   └── images/
│       ├── 01.jpg
│       └── 02.jpg
└── hotel-wifi/                 ← أو: صور إضافية لمشروع موجود بنفس اسمه
    └── meta.json               ← يكفي فيه حقل "images"
```

## الخطوات

1. أنشئ مجلدًا باسم إنجليزي بسيط داخل `public/projects/` (مثال: `clinic-network`)
2. ضع صورك داخل `images/` فيه (مثال: `images/01.jpg`)
3. انسخ القالب `meta.example.json` إلى ملف باسم `meta.json` داخل المجلد وعدّل بياناته
4. أضف اسم المجلد إلى القائمة في `public/projects/index.json`
5. شغّل `npm run dev` وافتح صفحة المشاريع — أو ارفع المجلدات مباشرة إلى السيرفر للموقع المنشور

## أين تظهر الصور؟

- **أول صورة** → تظهر تلقائيًا على كارت المشروع في صفحة المشاريع
- **كل الصور** → معرض داخل صفحة المشروع، والتعليق (caption) يظهر **جنب كل صورة**

## إضافة صور لمشروع موجود أصلًا

أنشئ مجلدًا بنفس اسم المشروع تمامًا (مثال: `public/projects/hotel-wifi/`) وضع فيه `meta.json` يكفي فيه حقل `images` — الموقع يدمج صورك مع البيانات الأصلية تلقائيًا.

## ملاحظات مهمة

- ✅ لا حاجة لأي تعديل في الأكواد إطلاقًا — الموقع يقرأ المجلدات تلقائيًا
- ✅ يعمل على النسخة المنشورة: ارفع الملفات إلى مجلد `projects` على الاستضافة مباشرة
- ✅ أي ملف ناقص أو خاطئ يتم تجاهله بأمان دون كسر الموقع
- القيم المسموحة لـ `market`: `"sa"` / `"eg"` / `"both"`
- `"featured": true` تعرض المشروع في الصفحة الرئيسية أيضًا
- القيم المسموحة في `catIds`: `it-infrastructure` · `networks` · `microsoft-cloud` · `security-systems` · `consultancy`
- التوصية للصور: JPG/WebP بعرض 1200–1600px وحجم أقل من 500KB، وسمّها بالأرقام (`01.jpg`, `02.jpg`) للترتيب
